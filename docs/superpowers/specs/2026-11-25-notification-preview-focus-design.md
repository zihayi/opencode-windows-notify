# 本轮通知预览与点击回到 CMD

目标：从通知看出刚完成了什么、有什么要处理；点横幅或通知中心里的同一条提醒，就回到运行它的终端。

## 方案

- **会话标题**能区分对话，但不能区分同一对话的不同轮次。用户选择了**本轮内容**：完成时摘取本轮最终回复的可见文字；提问时显示问题；审批时显示申请的操作。直接在本地摘录，不再调用模型生成摘要。正文过长时截短，没有内容时沿用固定提示。可以关闭正文预览。
- **精确回到标签页**：保留现有的 OpenCode Windows 通知。点击时由本机助手重新连接来源进程的控制台；传统 CMD 直接还原。对于 Windows Terminal 1.25，在来源控制台临时设置随机标题，用 Windows UI Automation 在对应窗口选中带这个标记的标签，然后恢复原标题并前置窗口。无需修改终端配置、模拟按键或记录标签序号。要求标签使用应用标题；已关闭或标题被锁定导致无法确认来源时不跳到其他页。仅前置窗口不满足用户需求，另开 CMD 也无法带回正在等待输入的现场。

延续现有通知去重、子会话和静默规则。点击只负责定位，审批和回答仍在终端完成。验证覆盖本轮隔离、正文回退、通知中心的点击信息，以及在两个同名标签间精确选回来源标签。更新本机已安装的插件。
